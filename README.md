#Dans le Backend#

1-créer une base de donnée vide

2-créer un fichier .env en copiant tous le contenu de .env.example et remplacer les info nécéssaire comme : l'utilisateur postgres, le mot de passe postgres et le nom de la base

3-exécuter dans la base crée le contenu de src/db/db.sql

4-npm install

5-npm run seed:admin

6-npm run dev

#Dans le Frontend#

1-npm install

2-npm run dev
